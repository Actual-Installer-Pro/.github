## How Actual Installer Pro Sits

Actual Installer Pro does not replace the files you already keep for software you own. It sits beside them as named wizard screens for an Actual Installer Pro shop package you ship.

## Traffic Light

| Signal | On the Actual Installer Pro package desk | What you do |
|--------|------------------------------------------|-------------|
| Green | Named project, screens on your package | Continue the same wizard desk |
| Amber | Screens from two packages mixed | Split the set before a large change |
| Red | No title, pages from everywhere | Stop and name the setup project first |
| Clear | Handoff written, page list short | Close Actual Installer Pro and leave the desk |

## Open Order

1. Open the last Actual Installer Pro session on a package you ship, not a new empty wizard.
2. Read the wizard screens and the last handoff.
3. Finish one visible page inside Actual Installer Pro setup project.
4. Write what changed on a package you own, then close with fewer loose pages than you found.

## After a Week

A week in Actual Installer Pro is not more live screens. It is the same setup project, a shorter page list, and a note that still makes sense on Monday. Leave the package desk quieter than the session you opened.

## Sign-off
